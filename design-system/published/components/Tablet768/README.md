# Tablet768

Foundation specimen at a 768px viewport, light then dark: header and nav, display hero, the live type ramp (sizes read from computed styles), three project cards and a case-study section.

- Type steps come from the `responsiveType` tokens through the media queries in `bundle.css` (768px tablet, 1024px desktop).
- Grid: `grid-columns-mobile|tablet|desktop`. Cards span 4 columns, so they fall at 1, 2 and 3 per row.
- The copy is sample content, and the artifact frames are placeholders for real project imagery.
